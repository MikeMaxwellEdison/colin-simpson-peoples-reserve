# Colin Simpson — The People’s Reserve

A private family-made Father’s Day collection published as a carefully curated public page.

The permanent address is:

https://mikemaxwelledison.github.io/colin-simpson-peoples-reserve/

## Family archive and video messages

The completed early-family story, including Hazel, Ron and Renée, appears inside the main
page’s family archive. Its photographs were prepared for the web from the family originals;
the supporting text photograph is intentionally not published.

Laura’s and Mike’s short portrait messages appear on the main page in the family sequence.
Their full-length messages are on `laura.html` and `mike.html`, using the supplied thumbnails.
All four videos are prepared as mobile-friendly H.264 files.

Shared captions are kept together in `editable-details.js`. Updating a caption there changes
every place that uses it while the permanent website address and QR code remain unchanged.

The little-white-ball calculator is in `golf-calculator.html`. It saves Colin’s entries and
latest result in the browser on the device being used, makes his personalised PDF certificate,
and can create a portable result link for carrying the estimate to a second device. The link
stores the calculator figures in its address rather than publishing them to the tribute. True
automatic cross-device saving needs an authenticated online data store; GitHub Pages alone is
read-only and cannot provide it safely.

The only planned family-content update is the permanent golf estimate. When Mike and Ally have
completed the eras, replace `window.COLIN_FAMILY_GOLF_ESTIMATE = null` in `editable-details.js`
with the finished segments. The page will calculate the family total and compare it with the
estimate Colin enters.

The main-page story links remember where they were opened so the return links can place the
reader back at the same spot.
